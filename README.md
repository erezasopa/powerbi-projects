# 📊 AdventureWorks Sales Dashboard

This Power BI dashboard analyzes sales performance, product categories, and regional data using the AdventureWorks dataset.

## 🔍 Overview

The dashboard provides insights into:
- Total sales by product and region
- Top-selling categories and subcategories
- Year-over-year sales trends
- Sales by customer segment
